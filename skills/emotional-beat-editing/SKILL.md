# 情緒卡點剪輯

一般卡點是「為了對拍而剪」，情緒卡點是「為了說故事、堆疊情緒而剪」。
先學會精準對拍，再學會**故意不對拍**：整支片都精準卡拍時，突然一個不切、不對拍、留白的鏡頭，
往往就是全片情緒最高點。

## 四個核心心法

### 1. 留白與呼吸（呼吸感卡點）
- 音樂從嘈雜副歌掉進安靜段（Bridge、間奏前的空拍、主唱換氣、一句重話唱完）時，**故意不切**。
- 同一個鏡頭拉長停留（3–6 秒以上），讓觀眾消化情緒，製造「空氣突然安靜」的窒息感。
- 實作：在情緒地圖的 `breath` / `drop` 點，剪輯表**不放切點**，讓前一個鏡頭延續，必要時選慢動作素材或用 `setpts` 放慢。

### 2. 音效情緒預熱（Sound Design Beat）
- 重拍落點前 0.5–1 秒，先放環境音或過渡音效（打火機喀擦、深吸一口氣、心跳、水滴、鐘聲尾韻、雷聲前的靜電）。
- 耳朵先被音效抓住，畫面再隨重拍爆出來，衝擊力會比單純對拍強很多。
- 實作：在剪輯表旁加一份 `sfx` 清單 `[(重拍時間 - 0.6, 音效檔, 音量dB)]`，合成時用 `adelay` + `amix` 疊在歌曲下方（見下方 ffmpeg 配方）。
- 音效素材必須由使用者提供或來自確定可用的免版稅來源；**不要自行下載來源不明的音效**。沒有音效就跳過這招，改用畫面預熱（例如重拍前 0.3 秒先閃一下白/紅）。

### 3. 動態對比（J-Cut / L-Cut）
- **J-Cut（聲音先行）**：畫面還在前一幕，下一幕的聲音（下一段的環境音、合唱、笑聲）先進來。
- **L-Cut（畫面先行）**：畫面已切到下一幕，前一幕的聲音還在迴盪。
- 用視覺和聽覺的時間差，激發對比、諷刺或失落感。
- MV 的歌曲本身是連續的，J/L-Cut 主要用在**音效層**和**字幕層**：
  - J：下一幕的音效／下一句字幕提早 0.3–0.8 秒出現，畫面晚一點才切。
  - L：畫面切走了，前一幕的音效尾巴（鐘聲、雷聲、掌聲）或前一句字幕的殘影（燒成灰、淡出）多留 0.5–1 秒。
- 諷刺型歌詞特別好用：歌詞唱「為民」，畫面已經切到紅酒包廂（L-Cut 字幕殘影）。

### 4. 畫面規模與情緒遞進（Scale Match）
| 情緒階段 | 鏡頭語言 | 切點密度 |
|---|---|---|
| 鋪陳／低谷 | 極端特寫：一滴眼淚、手、眼睛、失焦燈光、物件細節 | 疏（每 2–4 秒或更長） |
| 推升／轉折 | 中景、人物半身、慢推鏡 | 中（每 1–2 小節） |
| 副歌爆發／高峰 | 大遠景、全團、空拍、快速運鏡、爆炸火光 | 密（每 1–2 拍），但保留一兩個長鏡頭當錨 |
| 收尾 | 回到特寫或空景，鏡頭拉遠 | 疏，最後一個鏡頭最長 |

生成素材時就要照這張表下 prompt：鋪陳段要 `extreme close-up` 的分鏡，高潮段要 `wide shot / aerial / fast camera`。

## 敘事剪輯技巧（實戰）

以下來自《楚歌》（京劇霸王別姬×交響金屬）的剪輯回饋。 <!-- public-ok -->

### 服裝遞進：在歌詞轉折點換裝
- 同一個角色從頭穿到尾，整支片會很平。在歌詞的轉折句換裝，例如唱到「不施粉黛 換戎裝」時，宮裝換成戎裝。
- 換裝的那一句放一支「當場換裝」的劇情鏡頭當轉場（繫上戰甲、披風展開），之後的對嘴全部換成新造型。
- 對嘴靜圖要準備兩套：轉折前一套、轉折後一套，同一張臉、同一套妝。

### 臨終回憶蒙太奇：死前快速回顧一生
- 角色死亡或重大決定前，把全片用過的劇情鏡頭跟著節拍快速閃回。
- 節奏要加速：先兩拍一換，再一拍一換。大致照劇情的時間順序排，最後幾拍可以重複關鍵畫面。
- 每個片段的 `offset` 挑那支影片最乾淨的幾秒；交劍、重大畫面加 `flash`。
- 蒙太奇的最後停在決定性的鏡頭（例如持劍閉眼），再接結果（劍落）。

### 關鍵句之後不回對嘴
- 副歌的關鍵句（例如「力拔山兮」）一出來，就把畫面整個交給劇情和回憶，不要再切回唱歌的臉。
- 情緒推到頂點時，繼續看演唱反而會把觀眾拉出故事。

### 直式版的特寫疲勞
- 直式畫面從 16:9 素材裁出來，約放大 2.7 倍，對嘴鏡頭全是大臉。
- 張大嘴的長音特寫最多留 2 秒左右，前段也要每 2–4 秒插一個劇情畫面，不然會很死板。
- 字幕在直式裡要縮小（降低 `font_scale`），橫排放在頭頂上方和胸口以下，不要壓到臉。

### 對嘴和劇情可以用不同畫風
- 對嘴用嘴型比較好對的半寫實人像，劇情畫面用工筆國畫風，兩者穿插也能成立。
- 代價是同一個角色的頭飾、服裝細節會不同，要讓決策者先知道。

### 短版和完全版的劇情順序要分開想
- 短版可以在最後一句就讓角色死去；完全版後面如果還有橋段（例如交劍對答），死亡要移到橋段之後。
- 完全版不要直接 `@short` 貼上短版的結尾，先確認劇情順序再貼。

## 操作流程（配合 Dreamfab 的 MV 線）

1. **跑情緒地圖**：
   ```
   python mv/audio/emotion_map.py audio/song.wav audio/beats.json [audio/vocals.wav] > audio/emotion.txt
   ```
   輸出每小節的能量、情緒階段（low / build / peak / drop）、人聲呼吸點（breath）、能量驟降點（drop）、
   爆發點（hit），以及**建議的切點密度**。需要 librosa（`pip install -r requirements.txt`）。安裝成 Claude Code skill 時，腳本也在本 skill 的 `scripts/` 底下。
2. **先畫情緒曲線再排鏡頭**：把段落標成「鋪陳 → 推升 → 爆發 → 留白 → 再爆發 → 收尾」，每段決定鏡頭規模（心法 4）。
3. **排剪輯表**（`project.py` 的 `EDITS`，每列 `start src [offset] [flags]`）：
   - `peak` 段：切點對齊重拍（beat snap ≤ 0.08 秒），一拍到兩拍一切。
   - `low` 段：一小節以上才切，優先用特寫與長鏡頭。
   - `breath` / `drop` 點：**不要放切點**；前一個鏡頭延續過去。
   - 每個大段落找**一個**「故意不卡點」的位置：通常是爆發前最後一拍的留白，或高潮後第一個安靜小節。
   - `hit`（最強重拍）：配 `flash` 旗標或變速卡點。
4. **變速卡點**：重拍前用慢動作（`setpts=2.5*PTS`），重拍瞬間切回正常速度，讓動作的「瞬間」（出拳、甩頭、爆炸、鐘響）跟重低音重疊。
   做法是把同一個素材拆成兩段：重拍前慢速段 + 重拍後原速段。
5. **字幕也是卡點的一部分**：
   - 爆發段：字砸入、震動、閃白。
   - 留白段：字慢慢浮現，或乾脆不出字。
   - J/L-Cut：字幕提早或延後，製造諷刺。
6. **檢查**：抽格看「切點分布圖」：
   - 高潮段切點應該最密，鋪陳和留白段要明顯變疏。
   - 整支片至少要有 2–3 個超過 3 秒的長鏡頭。

## ffmpeg 配方

**音效預熱層**（疊在歌曲音軌下）：
```
-i song.mp3 -i sfx_lighter.wav -i sfx_breath.wav -filter_complex
"[1:a]adelay=12400|12400,volume=-6dB[s1];[2:a]adelay=30150|30150,volume=-9dB[s2];
 [0:a][s1][s2]amix=inputs=3:duration=first:normalize=0[a]"
```
（`adelay` 單位是毫秒，要用影片時間，所以要扣掉 cut 再加上片頭卡秒數。）

**留白前的抽空**（重拍前 0.5 秒把音樂壓低，只留呼吸音效）：
```
[0:a]volume='if(between(t,29.6,30.1),0.15,1)':eval=frame[a0]
```
只在使用者同意時才改動歌曲本身的音量；預設只動音效層。

**變速卡點**（重拍在素材 1.2 秒處）：
```
seg A: -ss 0 -t 1.2 -i clip.mp4 -vf "setpts=2.5*PTS"      → 3.0 秒慢動作
seg B: -ss 1.2 -i clip.mp4 -vf "setpts=PTS"               → 原速衝出
```
兩段接在一起時，B 的第一格要落在重拍上。

**長鏡頭拉長**：素材不夠長時，用 `setpts=<倍率>*PTS` 慢放（倍率 ≤ 1.8 看起來還自然），
或用 `tpad=stop_mode=clone` 定格。定格不要停在 AI 影片的最後 0.35 秒，常有雜訊。

## 黃金法則
- 先確保 80% 的切點精準對拍，剩下 20% 留給「故意不對拍」。
- 每個留白都要有理由：剛唱完一句重話、情緒轉折、高潮前的吸氣。
- 高潮不是切最多就好：密集切換中保留一個穩定的錨點鏡頭（主唱特寫、全團大景），觀眾才知道看哪裡。
- 收尾一定要比開頭慢。
