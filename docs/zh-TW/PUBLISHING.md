# 上架：封面、標題、說明欄、合集

中文 | [English](../en/PUBLISHING.md)

短劇是一集一集追的：每一集的封面、標題、說明欄要讓人**一眼認出是同一部劇、而且知道是第幾集**。包裝格式寫進 `style.md`，每集照著做。

## 封面

**素材來源：**
- 從片段抓畫面，不從成片抓（成片已經燒進字幕）：`ffmpeg -ss <秒> -i clips/<id>.mp4 -frames:v 1 thumb_src/<id>_<秒>.png`
- 用 `dramakit/thumbkit.py` 組版，範例見 `examples/demo/covers.py`。預設 1080×1920 直式；YouTube 橫式縮圖先設 `tk.W, tk.H = 1280, 720`。

**三個方向各做一張，挑一張用：**

| 版本 | 方向 | 版型 |
|---|---|---|
| A | 揭露 | 說出揭露那句的人，上方是鉤子文案（`tk.hook`），下方劇名 |
| B | 反轉 | 上下對切（`tk.split`）：被壓的那一刻／被打臉的那一刻，各配一句台詞 |
| C | 主角 | 主角單人，劇名、類型標籤（`tk.banner`） |

**規則：**
- 一張只講一件事：一張臉、一句鉤子。
- 文字不蓋臉；縮到 180 px 寬仍要讀得出來（手機的列表大小）。
- 直式封面的關鍵文字放在 y < 1440：App 會把標題疊在下緣。
- 集數放在固定位置（`tk.badge`），整部劇同一個版型。
- 鉤子可以爆雷到「發生了什麼」，不要爆雷到「為什麼」。

## 標題

**公式**：`《劇名》第N集｜這一集的鉤子`

- 鉤子用這一集最狠的台詞或最大的反轉：揭露身分的那一句、被打臉的那一刻。
- 第一集的標題加類型關鍵字：逆襲、重生、隱藏身分、甜寵……
- YouTube Shorts、Reels 的標題可以加 `#短劇`；長度控制在手機顯示得完的範圍（約 30–40 字）。

## 說明欄結構

1. 一句話介紹這部劇（`plan.md` 的一句話）
2. 這一集發生什麼（兩三句，不要爆雷卡點）
3. 合集連結（播放清單），以及上一集、下一集的連結
4. 角色表（名字＋一句身分）
5. 聲明：
   - 本片使用 AI 生成影像與語音（AutoIP），角色、情節皆為虛構
   - 聲音樣本的來源與授權（自己的聲音、合作演員、合成語音）
   - 配樂、音效的出處
6. hashtag：`#短劇 #劇名 #類型`，3–5 個

- 平台的「經過修改或合成的內容」揭露要勾選（YouTube Studio 的「變造或合成內容」）。
- YouTube API 的說明欄上限是 5,000 bytes，不是 5,000 字：中文一個字 3 bytes。

把標題、說明欄、hashtag 寫在每一集的 `YouTube_SEO.txt`（範本見 `examples/series_template/s1e01_title/YouTube_SEO.txt`）。

## 合集與更新節奏

- 每部劇一個播放清單，**照集數排序**（YouTube 的播放清單要先設成「手動排序」）。
- 固定時間更新（例如每天晚上 8 點一集），在說明欄、置頂留言寫下更新時間。
- 置頂留言放完整的集數目錄（第1集～最新一集的連結），每次更新時改。
- 第一集的封面和標題最重要：它是整部劇的入口，可以做兩三版測試。
- **整季合集另外上一支**：`python dramakit/compile.py <合集資料夾>`，`project.py` 的 `PARTS` 列出每一集（`end_card=False` 把各集的片尾卡拿掉，只留最後一集的）、銜接卡（`card=`）、其他影片（例如同一個人物的 MV），以及放在最前面的鉤子（`clips=[(集資料夾, 起, 迄), ...]`：從各集成片剪幾句最抓人的台詞，白閃接起來；字幕燒在畫面上，剪點不要切到前後句，切到了會提醒）。每一段各自壓到同一個響度，輸出合併字幕和 `<NAME>_chapters.txt`，章節直接貼進說明欄。

## 平台規格

| 平台 | 比例 | 長度 | 備註 |
|---|---|---|---|
| YouTube Shorts | 9:16 | 3 分鐘以內 | 自訂縮圖只能在電腦版 Studio 上傳 |
| Instagram Reels | 9:16 | 依平台規定 | 封面可另外上傳 |
| TikTok | 9:16 | 依平台規定 | |
| YouTube 一般影片 | 16:9 | 不限 | 多集合輯用 `ASPECT="16:9"` 或另出橫式版 |

字幕已經燒進畫面；`.srt` 另外上傳成 CC 字幕，聽障觀眾與搜尋都用得到。
