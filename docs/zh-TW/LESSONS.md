# 踩坑紀錄

中文 | [English](../en/LESSONS.md)

這些都是實際做 MV 時遇到的問題。每條都有對應的程式碼或流程處理；括號內是負責處理的檔案。

## 生成：通則

- **點數送出即扣，沒有取消 API。** 任務一旦送出就停不下來，所以在送出前把關：
  - 先產生靜圖並做審核圖（`qc/sheets.py`）。
  - 群像、新角色、改過 prompt 的畫面，一律先看圖再送影片。
- **失敗的任務會自動退點。** runner 遇到失敗會自動重試，最多 3 次（`aip_runner.py`）。
- **同時任務數上限。** 一般帳號同時只能跑 1 個任務，超過會回 429 `concurrency_limit`。
  - runner 預設 `AIP_MAX=1`，遇到 429 就等目前的任務結束，不會一直重送。
- **「2k」影片解析度反而更差。** 實測 2k 選項只輸出 864×480，還要 288 點。768p 輸出 1344×768，只要 75 點。
- **圖生圖素材裡有什麼，結果就會有什麼。** 例如素材裡有鋼琴，管風琴手怎麼改 prompt 都還是彈鋼琴。
  - 解法：換成文生圖重做那張靜圖，prompt 寫具體構件（「四層鍵盤、成排音栓、身後巨型風管」）並加 `no piano`。
  - 或是只拿臉部特寫當參考圖，讓模型自己畫樂器；也可以拿另一個專案已經成功的同類畫面當底，低強度（約 0.6）只換背景元素。
- **圖生圖會繼承參考圖的畫風。** 想整集換畫風（例如從半寫實改成工筆國畫），要先用新畫風重做定裝圖，之後的人物鏡頭都拿新定裝圖延伸。
  - 圖生圖只有 standard / hd_4k，選不到文生圖的 `v3` 這類風格模式，所以畫風要靠定裝圖帶。
  - 差很多的畫風（例如仿顧愷之〈洛神賦圖〉的古畫）連圖生圖都拉不過去，強度 0.75 仍是原來的工筆。只能用文生圖重做，人物描述要寫得很具體（面具在哪半邊臉、冠的形狀）。
- **直式定裝圖墊成 16:9：**
  - 兩側補模糊色塊的話，強度 0.8 以下結果還是「直式人像＋模糊邊」，場景換不出來。
  - 解法：只裁頭到胸，兩側用鏡像延伸補滿，再用 0.9 左右做圖生圖。
  - **全身圖不要鏡像延伸**：兩側的鏡像會被畫成另外兩個人。全身鏡頭改用同場景空景模糊當底，或直接文生圖。
- **用「頭到腰」的裁切延伸成全身，會頭大腿短。** 頭的比例被參考圖固定住了。
  - 全身鏡頭要用全身參考圖，prompt 寫「tall, long legs, heroic proportions」，negative 加「short legs, stubby body, big head, chibi」。
  - 寫 `muscular` 常畫成赤膊或裸臂，改寫「powerfully built, fully covered in armor」，negative 加「bare arms, bare chest」。
- **文生圖的構圖好，但角色長相會跑掉。** 例如京劇霸王長出黑色長鬍子、臉譜變成紅臉；negative 寫了 beard 也擋不住。
  - 修法：把定裝圖的頭部（臉譜加頭盔）貼到畫面裡的頭部位置，用羽化橢圓遮罩，再以約 0.45 的強度做圖生圖融合。
  - 原圖的長鬍子比臉大很多時，貼頭蓋不掉，模糊或複製旁邊紋理去蓋都會留痕跡。改挑一張本來就沒有長鬍子的構圖再貼頭。
- **雙人同框的靜圖很難做。** 兩張定裝圖拼貼後圖生圖，接縫會留下來；文生圖又會跑掉長相。改用多參考影片直接拿定裝圖生成，跳過靜圖。
- **鏡子會生出第二張臉。** 「對鏡梳妝」的倒影常畫成另一張正臉。改成鏡面斜放、只映燭光，negative 加「face in the mirror, two faces」。
- **精細手勢在靜圖裡做不出來。** 例如「反手握劍貼頸」試了 4 次都畫成正手。靜圖只拍持劍閉眼，反手握的動作寫進圖生影片的描述。
- **帳號開啟 NSFW 時，文生圖可能生成裸體。** 例如「霸王抱著已無生命的虞姬」生成了裸體人物。所有人物 prompt 的 negative 都加 `nude, nsfw`，生成後每張都要看過再往下走。

## 對嘴（lip-sync）

- **片尾約 0.2 秒常出現白色雜訊。** 合成時永遠不用最後 0.35 秒（`RENDER.tail_guard`）。
- **前幾秒可能沒動嘴，中段可能拉遠成全身。**
  - 用 `qc/mouth.py timeline` 找出可用區間。
  - 剪輯表只取有動嘴、臉夠大的那幾秒，不足的部分用另一個場景的同段對嘴補上。
- **常常在畫面底部燒進亂碼字幕。** 用 `RENDER.crop` 裁掉，例如 `crop=1024:576:180:0`。字幕不一定整段都有，每段對嘴都要抽格看底部。
- **輸出片長常比要求的短 0.2–0.6 秒。** 例如要 22 秒給 21.8 秒、要 29.5 秒給 28.9 秒。
  - 剪輯表照 `align.json` 的 `dur` 排，不要照送出的長度排。
  - 合成時印出 `WARN ... short by ... -> freeze tail` 代表那一格會定格，看起來像跳格，一定要改剪輯表，例如讓前一個劇情鏡頭撐久一點。
  - `WARN ... before clip start` 代表對嘴從錯的位置開始，嘴型會對不上，同樣要改。
- **墊底靜圖的表情會帶進整段對嘴。** 張嘴笑的靜圖拿去唱悲歌，整段看起來都在笑。靜圖的表情要先符合那段歌的情緒，negative 可加「smiling, grin」。
- **輸出音訊不一定從你送的起點開始。** 用 `qc/align.py` 做 onset 互相關，求出實際起點。合成時依此計算 offset，嘴型才會和歌曲同步。
- **雙主唱絕對不要送整軌人聲。** 送整軌的話，兩個人的嘴會在所有句子都動。
  - 先用 `voice_probe.py` 標出各聲部的時段，再用 `split_voices.py` 切成兩軌，每軌加 50 ms 淡入淡出、−36 dB 底噪。
  - 每支對嘴只吃自己那一軌。
- **單次上限約 30 秒。** 長段落分成多段；同一段音訊生成 2–3 個不同場景，剪輯時輪替使用。
- **人像圖要 10 MB 以內。** 圖生圖 hd_4k 的輸出常超過，會被拒絕（不扣點）。先縮成 1920×1080 再送，原圖另外留一份。
- **亂碼字不只出現在底部。** 有一段在畫面右下、人物手邊燒進兩行字；這時從左上裁一塊 16:9（例如 `crop=900:506:0:0`），放大後會稍軟。

## 圖生影片（I2V）

- **羊皮紙、文件、招牌常冒出亂碼字。**
  - prompt 寫「completely blank ... with no writing」。
  - 影片 prompt 加「畫面中不要出現任何文字」。
  - 仍然出現時，剪輯只取前段乾淨的部分。
- **人物會中途換臉。** 例如鼓手 1.5 秒後變成別人。
  - 用 `qc/sheets.py video` 抽格確認。
  - 剪輯表只用換臉前的秒數（`start src offset`，片段要短）。
- **共用的 `MOTION_PREFIX` 寫了角色或道具，模型會把它們塞進每一支影片。** 例如前綴寫「霸王與虞姬、楚旗」，空景烏騅 2 秒後冒出楚旗和人物，換甲的虞姬 1 秒後換成另一個女子。
  - 前綴只寫畫風，不寫角色、道具。
  - 每支影片的描述開頭寫「單一連續鏡頭，不要切換畫面，同一個人、同一張臉，不要換人」。
- **即使前綴乾淨，影片後半還是常冒出不該有的人。** 《帷影》一批 27 支裡就有 7 支：1–3 秒後多出別的皇帝、屏風旁冒出露臉的女子、面具變成京劇臉譜。每支影片要逐秒抽格（不是只看頭中尾），把能用的秒數寫進 EDL 註解，只剪前段。
- **影子也算一個人。** 紙屏上的人影、牆上的影子，觀眾會當成第二個人。故事規定「只有一個人」時，不要寫屏風或投影，negative 加 `shadow, silhouette on screen`。

## 群像

- **多參考影片容易把人變矮、變成小孩、縮成遠景。** 改 prompt 寫「高挑、腰上」也不太有效。
- **解法：先自己構圖。** `group_still.py` 的流程：
  1. 把每位成員的頭胸裁切並排成拼貼。
  2. 以 0.85 / 0.92 的強度做圖生圖，prompt 加「mature adults around thirty, sharp jawlines, low angle, waist-up」，negative 加「childlike, baby face, chibi, full body」。
  3. 人工挑定稿後，再走一般的圖生影片。
- 強度低於約 0.8 時，拼接縫會留下來。
- 人工審核時，要特別確認「看起來像不像小孩」。

## 字幕（libass / ASS）

- **同一個事件裡，第一個 `\pos` 或 `\move` 生效，後面的會被忽略。** 想讓圖形移動時：
  - 不要在 `\move` 前面先放 `\pos`。
  - `epic.shape()` 遇到 `\move` 時會自動省略 `\pos`。
- **可變字型只會渲染預設字重。** 指定 Black 也只會出 Regular 或 Light。
  - 解法：用 `make_static_font.py` 切出靜態字重，並改用新的家族名稱。
- **libass 字級和 PIL 量到的大小不同。** 要乘上 `font_scale`（Noto Serif TC 約 1.45）；換字型後先用 `subprev.py` 校正。
- **ffmpeg 的 `drawtext` 在部分 Windows 版本會因 fontconfig 崩潰。** 審核圖的標籤改用 PIL 畫（`qc/sheets.py`）。
- **片名卡不要蓋住主唱的臉。** 片名在高潮重拍砸入後約 1.4 秒就要縮到畫面上緣；若主唱在畫面上方，換鏡頭。
- **序幕片名停 5 秒就好。** 片名預設停到序幕結束，序幕有 40 秒時會一路掛著，使用者覺得太久。設 `TYPO.intro_title_s=5`、`title_step=1`（一拍一個字快速燒出）。不要自己加集數字卡，除非使用者要。
- **韻腳標音要用作詞者註記的唱法。** 不要自行推字典讀音，例如作詞者標「乾杯 (pe)」，字典讀音卻是 kan-pue。
- **字幕預覽和成片分開做。** 只渲字幕的預覽幾秒就好，完整合成要好幾分鐘。

## 語音辨識

- **台語、嘶吼、重混音的 ASR 文字幾乎不能用，但時間點可以用。** 做法：
  1. 以歌詞全文作為 `initial_prompt`。
  2. 只辨識有人聲的區段，並關掉 `condition_on_previous_text`。
  3. 字幕引擎以 difflib 把歌詞字元對上 ASR 字元，對不上的部分在句首時間之間平均分配。
- 句首時間要人工確認。
- **嘶吼段可能連時間點都抓不到。** 這時用前後兩個辨識得到的句首當錨點，中間的句子平均分配，合成後再看字幕微調。
- **慢板吟唱、長音的段落，ASR 字的時間會早半秒到一秒多。** 使用者會覺得「歌詞趕不上」。用人聲音軌每 0.25 秒的 RMS 找出每句的起音，直接改寫 `words.json` 那一段（先備份）。

## 剪輯與合成

- **完整版和短版各自的 EDL 曾經混用。** 用短版 EDL 渲出了 70 秒的「完整版」。
  - 現在剪輯表在合成時才從 `project.EDITS[mode]` 解析，不再有中間檔。
- **素材不夠長時：**
  - 一般片段用 `setpts` 放慢，1.8 倍以內看起來還自然。
  - 對嘴片段不能變速，否則嘴型會對不上，改用 `tpad` 定格。
- **切點吸附到節拍時，容許 0.08 秒誤差。** 超過就保留原時間，那通常是刻意不卡拍的位置。
- **AI 寫實人像要做平台揭露。** 縮圖、標題、標籤都不要放真實人物或政黨名稱，政治諷刺尤其要注意。

## 工具使用

- 在 Windows 上，用 bash heredoc 寫含 `\\`、`\n` 的 Python 字串容易被吃掉。修補腳本請寫成檔案再執行。
- 每個任務資料夾的 `*.state` 記錄了 task uuid，用 `credits.py` 可以統計每個專案實際花了多少點。
- 改了 `project.SECTIONS` 之後要重跑 `storyboard.py`。合成讀的是 `storyboard.json`，不重跑的話，舊的段落時間還在，片名會蓋到臉。
- 任務檔裡的 `files` 是相對路徑時，`aip_runner.py` 要在專案資料夾內啟動。在 repo 根目錄啟動會找不到圖檔，每個任務都送出失敗；不要用 grep 把 runner 的輸出過濾掉，否則看不到錯誤。
