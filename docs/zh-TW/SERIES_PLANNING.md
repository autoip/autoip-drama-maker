# 整部劇的企劃框架

中文 | [English](../en/SERIES_PLANNING.md)

一集照 [WORKFLOW.md](WORKFLOW.md) 做。一部短劇常是 20–80 集，每集 1–2 分鐘；開拍前先用這份把整部劇規劃好。空白範本在 [`examples/series_template/`](../../examples/series_template/)。

這是框架，不是範本。**公式**管的是「觀眾為什麼會一集接一集看下去」；**自由**留給「講什麼故事、長什麼樣」。框架只規定要填哪些格子，不規定格子裡填什麼。

| 公式（每部劇都要有） | 自由（全部由你決定） |
|---|---|
| 一句話定這部劇 | 題材、類型、集數 |
| 一個爽點引擎：每集重複的「壓 → 揚」 | 壓的是什麼、揚的是什麼 |
| 每集同一個結構：鉤子、衝突、爽點、卡點 | 每段長度、怎麼演 |
| 幾個大揭露把全劇切成篇章 | 揭露什麼、放在第幾集 |
| 固定的角色造型與聲音 | 長相、聲音、人數 |
| 固定的包裝（封面、標題、片名卡、卡點） | 包裝長什麼樣 |
| 每集一張分集卡 | 卡片裡的故事 |

## 1. 一句話

**公式**：`{主角的處境} × {隱藏的東西}，{觀眾等著看的那一刻}`

- 「<被看不起的小人物> × <沒人知道的身分>，等著看<看不起他的人>知道真相」
- 「<處境很糟的主角> × <一個別人沒有的能力>，等著看<這個能力>扭轉局面」
- 「<被背叛過的主角> × <記得未來會發生什麼>，等著看<背叛的人>一個一個被拆穿」

範例只有格子，故事由你填；不要照搬現成作品的劇情或人設。

一句話講不出「觀眾等著看的那一刻」，這部劇就還沒有引擎。

## 2. 爽點引擎：壓 → 揚

**公式**：找一個每集都能重來一次的循環：主角**被壓**（羞辱、誤會、搶走）→ 主角**揚起來**（反擊、揭露、打臉）。觀眾追的是這個循環，不是劇情細節。

| 引擎 | 壓 | 揚 |
|---|---|---|
| 隱藏身分 | 被當成小人物看不起 | 身分一點一點露出來 |
| 重生／預知 | 前世被背叛 | 這次先一步拆穿 |
| 金手指 | 處境很糟 | 一個能力扭轉局面 |
| 反差 | 外表弱 | 實力強 |
| 復仇 | 被奪走一切 | 一個一個討回來 |

- **每集至少完成一次小循環**（一個反派被打臉），**每幾集一次大循環**（一個大揭露）。
- 壓的時間要短，揚的時間要長。壓太久，觀眾會滑走。
- 下一季換一個引擎，或同一個引擎換更大的對手。

## 3. 每集的結構

**公式**：整部劇每集同一個結構，觀眾會在同一個位置期待同一件事。

| 段落 | 1 分鐘一集 | 做什麼 |
|---|---|---|
| 鉤子 | 0–3 秒 | 衝突的正中間，或上一集卡點的答案 |
| 衝突 | 3–35 秒 | 壓：一個人一個人逼上來，一句比一句狠 |
| 爽點 | 35–50 秒 | 揚：揭露、反擊、打臉，配反應鏡頭 |
| 卡點 | 最後 3–5 秒 | 新的問題：下一集才回答 |

- **上一集的卡點，就是這一集的鉤子。**
- 第一集的前 10 秒要交代主角的處境（誰、被怎麼壓），之後每集不再介紹。

## 4. 篇章與大揭露

**公式**：用 3–5 個大揭露把全劇切成篇章，每個篇章 8–15 集。大揭露放在篇章的最後一集。

- 平台的付費點（如果有）通常放在第一個大揭露之前：觀眾已經上鉤、還沒拿到答案。
- 每個篇章換一個主要反派，或換一個更大的場面（從一個房間到一間公司到一個家族）。
- 先把篇章表填完，再寫第一集。篇章表寫不出來，通常是引擎太小，撐不了這麼多集。

## 5. 角色與聲音：固定下來

`characters.md` 在開拍前寫好，之後每一集都照它：

- **主要角色 3–6 個**，每個人一句話人設、一套造型、一段聲音樣本、一句口頭禪（選用）。
- **一個篇章一套造型**。換裝是新的定裝圖、新的 key，寫進 `characters.md`。
- 聲音樣本整部劇用同一段。換了，觀眾會聽出來。
- 路人用背影、遠景、模糊處理，不要讓陣容以外的臉搶戲。
- 關係圖寫清楚：誰知道主角的秘密、誰不知道。這張表決定每一集誰會被打臉。

## 6. 風格聖經：固定幾個錨點

`style.md` 在第一集開工前寫草稿，第一集做完再照成品定稿。

**公式**：從下表挑 **4–6 個錨點**固定下來，其餘每集自由。

| 層 | 可以固定的錨點 | 可以每集換的 |
|---|---|---|
| 畫面 | 畫風與光線（`STYLE`、`MOTION_PREFIX`）、畫面比例 | 場景、時段 |
| 角色 | 定裝圖、聲音樣本、人物字卡樣式 | 出場的人 |
| 剪輯 | 鉤子的形式、爽點的處理（推近＋音效）、卡點的定格與字 | 鏡頭數、節奏 |
| 聲音 | 主題配樂、卡點音效 | 每場的配樂 |
| 包裝 | 封面版型、標題格式、片名卡 | 鉤子文案 |

- **卡點和封面最該固定**：觀眾靠這兩個認出這部劇。
- 固定太少看不出是同一部劇；全部固定，第五集就膩了。

## 7. 每集一張分集卡

`plan.md` 裡每集寫一張，欄位固定：

- **一句話**：這一集誰被打臉
- **鉤子**（前 3 秒的畫面與台詞）
- **壓**：誰、怎麼壓
- **揚**：怎麼反擊、揭露了什麼
- **卡點**：最後一格與那句台詞
- **出場角色、場景**：新的角色或場景要先做定裝（點數）
- **新角色／新造型**
- **預估鏡頭數與點數**

整部劇（至少整個篇章）的卡片先寫完，再寫第一集的劇本。寫卡片時常會發現兩集的打臉方式一樣、或卡點接不上，這時候改不用花點數。

## 8. 預算

一集 1 分鐘約 10–16 鏡。以多參考影片為主時，影片大約每集 800–1,500 點（示範集 11 鏡約 870 點），加上首幀靜圖與重拍；定裝、場景整部劇只做一次。先做第一集，用 `dramakit/credits.py` 稽核實際花費，再估整部劇。

## 目錄與命名

```
projects/<劇名>/
  plan.md               一句話、引擎、篇章表、分集卡、待確認
  style.md              風格聖經：固定的錨點、包裝格式
  characters.md         人設、造型、聲音樣本、關係圖
  cast/ sets/ props/    整部劇共用的參考圖（project.py 寫 ../cast/A.png）
  voices/               聲音樣本
  music/ sfx/ fonts/    共用的配樂、音效、字型
  s1e01_<集名>/         s{季}e{兩位數集數}_{集名}：照順序排
  s1e02_<集名>/
```

每一集的資料夾：

```
s1e01_<集名>/
  project.py          這一集的全部設定（PROJECT_FORMAT.md）
  劇本_v1.md …        改版就加版號，不覆蓋
  YouTube_SEO.txt     標題、說明欄、hashtag
  lines/              對嘴鏡頭的錄音
  kf/ clips/ jobs/ out/ covers/ …     生成檔
  rejected/ clips_rejected/           被退的版本：搬過去，不要刪
```

- 集數用兩位數（`s1e01`），超過 99 集用三位數。
- **資料夾在第一次送 AutoIP 任務之前定名**（任務檔寫的是絕對路徑）。
- 素材都不進 git。

## 每一集的順序

1. 對照 `style.md`、`characters.md` 和這一集的分集卡，寫 `劇本_v1.md`。
2. 新角色、新造型、新場景先做定裝，**給使用者確認**，寫進 `characters.md`。
3. 第一集從 [`examples/demo/project.py`](../../examples/demo/project.py) 開始；之後每集複製**上一集**的 `project.py`，`CAST`、`SETS`、`TYPO`、`RENDER` 沿用，換 `SCENES`、`SHOTS`、`EDITS`、`MUSIC`。
4. 照 [WORKFLOW.md](WORKFLOW.md) 做完。
5. 照 `style.md` 的包裝寫 `YouTube_SEO.txt`、做封面（[PUBLISHING.md](PUBLISHING.md)）。
6. 回頭更新：`plan.md` 的分集卡打勾；踩到的坑記下來，通用的寫進 [LESSONS.md](LESSONS.md)。

## 上架前的一致性檢查

- [ ] 鉤子接得上上一集的卡點
- [ ] 這一集完成了一次壓 → 揚
- [ ] 角色造型、聲音跟 `characters.md` 一致
- [ ] 卡點的定格、字、音效跟前幾集一樣
- [ ] 封面版型、標題格式跟前幾集一樣
- [ ] 說明欄連回第一集與合集

## 跟 agent 說

```text
用 autoip-drama-maker 規劃一部 30 集的短劇：<題材>
```

agent 會先問你題材、引擎、篇章和想固定哪些錨點，寫好 `plan.md`、`characters.md`、`style.md` 給你確認，才開始寫第一集。它不會套用任何現成作品的劇情或人設。

```text
照 projects/<劇名>/plan.md 做第 3 集，從第 2 集的 project.py 開始
```
