# 短劇剪輯心法

中文 | [English](../en/EDITING.md)

直式短劇的觀眾拇指放在螢幕上，隨時會滑走。剪輯只做一件事：**讓下一秒比現在更想看**。這份是剪 `EDITS` 時的判斷依據；寫法見 [PROJECT_FORMAT.md](PROJECT_FORMAT.md#剪輯-edits)。

## 1. 前 3 秒：從衝突中間開始

- **第一列就是最衝的一刻**：拍桌、甩巴掌、當眾退婚、一句狠話。不要從空景、片名、走路進場開始。
- 開場可以倒敘：先放這集最高潮的 2 秒，再接「三小時前」（`label=三小時前`）。
- 片名卡（`title`）放在第一個衝突**之後**，蓋在空景或過場上；不要讓片名擋住開場。
- 第一句台詞 3 秒內要出來。`auto` 列已經把台詞前的空白剪到 0.15 秒。

## 2. 對話：正反打

一顆鏡頭一個人說話，對話靠剪接接起來：

```
S2_01 auto            # 他說
S2_02 auto            # 她回
S2_03 auto zoom       # 他逼近（推近）
```

- **誰說話就看誰**，這是預設；例外是下面的反應鏡頭。
- 兩句之間的空白不要超過 0.3 秒。吵架戲要搶話：上一列的 `dur` 剪到最後一個字一結束就切，下一列的 `in` 往後挪到開口前一瞬。一般列是一列接一列播的，兩句的聲音不會真的重疊；要「一邊說、一邊看到對方」用插入列（見第 3 節）。
- 同一個人連講兩句，中間插對方的反應，不要一直停在同一張臉。
- 鏡頭大小跟著情緒走：平常中景，壓迫、威脅、心虛用近景和特寫。

## 3. 反應鏡頭：觀眾要看的是被打臉的人

爽劇的爽，一半在說話的人，一半在聽的人。用插入列（`^`）把聽的人的臉蓋在說話的人的聲音上：

```
S2_08 auto zoom sfx=hit         # C 說出揭露的那一句
^S2_09 0.3 0.9 @-0.9            # B 的表情凝固（聲音還是 C 那句）
```

- **L cut**：上一句還沒講完就切到聽的人（插入列放在上一列的尾巴，`@-0.9`）。
- **J cut**：下一句先出聲、畫面晚一點才切過去（插入列從上一列尾巴延伸到下一列開頭）。
- 反應鏡頭 0.6–1.5 秒就夠，長了就變成發呆。
- 一場戲裡最重要的那句台詞，至少配一個反應鏡頭。

## 4. 節奏

- 平均一鏡 1.5–3 秒。超過 4 秒的鏡頭要有理由：一段完整的狠話、一個要讓觀眾看清楚的表情。
- **刪掉所有「走過去」「坐下來」「轉頭」的過程**，直接切到結果。
- 每 15–20 秒要有一個新資訊或新衝突；沒有就刪。
- 一集裡只有一個地方可以慢：揭露之後的那一拍（定格、慢推、反應）。

## 5. 爽點：揭露、反擊、打臉

一集至少一個。這一刻要「重」：

- `zoom`：0.25 秒內推近，整列保持。揭露那句台詞、震驚的臉都可以用。
- `sfx=hit`：重擊、心跳、玻璃碎裂、低頻 boom。音效比畫面更直接。
- `flash`：白閃，用在最強的那一下，一集一兩次就好。
- 配樂在爽點**換一首**（`MUSIC` 從這一列開始新的一段），或在爽點前一拍突然停掉、爽點再進。
- 揭露之後馬上給身分字卡：那一列加 `intro=A`，字卡上的職稱來自 `CAST["A"]["title"]`（揭露後的身分）。字卡是揭露的一部分，不是介紹。

## 6. 卡點：停在問題上

- 最後一列停在**還沒有答案的那一刻**：轉身、一句話說一半、門打開看不到是誰、對方的表情。
- `freeze=1.6 end`：定格、降飽和、「未完待續」。定格要停在臉上，不要停在動作模糊的那格。
- 卡點前一句台詞最好是問句或威脅，讓觀眾帶著問題滑到下一集。
- 每集卡點的形式固定（同樣的定格、同樣的字、同樣的音效），觀眾會把它認成這部劇的記號。

## 7. 字幕與字卡

- 直式短劇大多靜音播放：**每一句台詞都要有字幕**，字幕不能晚於聲音。
- 一段字幕 14 字以內，依標點切；一個畫面不要同時出現兩段。
- 人物字卡只在第一次出場、或身分揭露時出現，一集最多三四張。
- 字不要蓋到嘴：臉在下方的鏡頭，把 `TYPO.sub_y` 調高，或換一顆構圖。

## 8. 聲音

- 對白最大，配樂退後。配樂在對白出現時會自動壓低（ducking），但音量本身還是要在 `MUSIC` 調：大多 −14 到 −20 dB。
- 生成的片段自帶環境音，換鏡時環境音會跳。同一場戲用同一段配樂蓋住，跳動就不明顯。
- 音效一集 3–6 個就好，全部都加會變吵。

## 9. 檢查清單

- [ ] 第 3 秒內有衝突，第一句台詞已經出來
- [ ] 片名卡沒有擋到開場
- [ ] 兩句台詞之間沒有超過 0.3 秒的空白
- [ ] 最重要的台詞有反應鏡頭
- [ ] 至少一個爽點（推近、音效、換配樂）
- [ ] 最後一格停在問題上，「未完待續」出現在定格上
- [ ] 合成沒有 `WARN`
- [ ] 每一句都有字幕，沒有蓋到嘴
